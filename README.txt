SITO EVENTI SPECIALI - PUBBLICAZIONE GRATUITA

1. Apri https://github.com/ dal browser e crea un account (se non ne hai uno).
2. Crea un nuovo repository pubblico chiamato esattamente: TUONOME.github.io
   Sostituisci TUONOME con il tuo username GitHub.
3. Nel repository premi Add file > Upload files e carica index.html.
4. Premi Commit changes.
5. Apri Settings > Pages.
6. In Build and deployment scegli Deploy from a branch; seleziona main e / (root), poi Save.
7. Attendi qualche minuto. Il sito sarà su https://TUONOME.github.io

PERSONALIZZAZIONE OBBLIGATORIA:
- In index.html cerca 393331234567 e sostituiscilo con il tuo numero WhatsApp in formato internazionale senza + o spazi.
- Cerca info@esempio.it e sostituiscilo con la tua email.
- Cerca "Eventi Speciali" e sostituiscilo con il nome del tuo brand.
- Puoi modificare testi, foto e servizi direttamente nell'HTML.

Nota: GitHub Pages ospita gratuitamente siti statici. Non include un carrello con pagamenti, un database o gestione ordini automatica. I pulsanti WhatsApp e email funzionano dopo aver inserito i tuoi contatti.
